# python-practice

Учебный проект по Python: классы товара и корзины, загрузка данных из JSON с обработкой ошибок.

## Как запустить

1. Скачать проект:

```bash
<git clone https://github.com/gamletdzalilov-lgtm/python-practice.git>
 

<cd python-practice>

```

2. Создать и активировать виртуальное окружение:

```bash
<python3 -m venv .venv>
 
<source .venv/bin/activate>

```

3. Установить зависимости:

```bash
<pip install -r requirements.txt>

```

4. Запустить проверки:

```bash
<python3 prostozafachi.py>
```

Если всё в порядке, выведется «Все проверки прошли успешно!».
